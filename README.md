# Hotel Room Reservation System

A full-stack Hotel Room Reservation System developed as a **Second-Year Higher Diploma (HD) Final Group Project**. The system provides an efficient platform for hotel room booking, reservation management, payment processing, customer reviews, and administrative reporting.

##  Features

###  User Application

* User registration and secure **Email OTP authentication**
* Browse available hotel rooms
* Real-time room availability checking
* Facility-based room search and filtering
* Room and meal selection
* Automated booking cost calculation
* Reservation and booking verification
* Advanced **bank transfer payment gateway**
* Real-time reservation and confirmation status updates
* Submit and manage hotel reviews

###  Admin Application

* Dedicated administrator dashboard
* Manage rooms, facilities, users, and reservations
* Monitor and verify customer bookings
* Manage and moderate customer reviews
* Track payment and reservation information
* Real-time booking and confirmation management
* Generate automated **weekly, monthly, and annual reports**
* View reservation and revenue-related statistics

##  System Workflow

```text
User Registration
       ↓
Email OTP Verification
       ↓
Search & Check Room Availability
       ↓
Select Room & Facilities
       ↓
Meal Selection & Cost Calculation
       ↓
Booking Confirmation
       ↓
Bank Transfer Payment
       ↓
Admin Verification
       ↓
Real-Time Reservation Confirmation
```

##  Reporting

The system automatically processes reservation and booking data to generate:

* Weekly reports
* Monthly reports
* Annual reports
* Reservation statistics
* Booking and payment summaries

##  Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap, jQuery
* **Backend:** PHP
* **Database:** MySQL
* **Authentication:** Email OTP
* **Payment:** Bank Transfer Payment Gateway
* **Architecture:** Full-Stack Web Application
